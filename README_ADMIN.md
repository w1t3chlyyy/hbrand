# Hustlify: каталог, Supabase и админ-бот

## 1. Залить в репозиторий
Распакуйте архив поверх проекта и закоммитьте. Править `src/App.tsx` вручную не нужно: `npm run dev` и `npm run build` сами запускают `scripts/patch-app.mjs` (идемпотентный), поэтому Vercel соберёт уже обновлённую версию.

## 2. Supabase
SQL Editor → выполнить по очереди `supabase/schema.sql`, затем `supabase/seed.sql` (6 текущих товаров).
Project Settings → API: скопировать URL, anon key и service_role key.

## 3. Telegram-бот
Создайте бота в @BotFather, узнайте свой ID у @userinfobot.

## 4. Vercel → Settings → Environment Variables
Все переменные из `.env.example`. Секрет вебхука — любая случайная строка.
После деплоя зарегистрируйте вебхук (один раз):
```
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://<ваш-домен>/api/telegram" -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```
Отправьте боту /start. Если бот пишет «Нет доступа» — добавьте показанный ID в TELEGRAM_ADMIN_IDS.

## Что умеет бот
- Товары: список, добавление пошагово (название → цена → категория → описание → фото → видео), правка любого поля, фото и видео загружаются прямо в чат, опубликовать/скрыть, пометка «Новинка», удаление.
- Новинка: название, подпись, текст и фон баннера в каталоге, включить/выключить.
- Заявки: анкеты и заказы с сайта приходят сразу с кнопкой «Обработано», раздел со списком необработанных.

Локально `/api/*` работает только через `vercel dev` (в `npm run dev` отправка анкет не сработает).
